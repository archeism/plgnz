# Bounded prior art decision

Inspected source, not README prose:

- `vercel-labs/skills@7407f3893ad4dceab546ac002c3ef806e4000c73`: `src/use.ts` and tests accept local skill sources, require an explicit selector for multi-skill sources, and materialize supporting files; `src/sync.ts` uses a folder hash for refresh.
- `neon-solutions/add-mcp@37c8246d6beeb0779507bb30f9a69376a344cce7`: `src/lib.ts` exports a config-writer API (`upsertServer`, `removeServer`); `src/types.ts` models agent capability-gated MCP config transforms; `src/source-parser.ts` distinguishes remote, package, and command inputs.

## Decisions

Adopt from `skills`: explicit multi-item discovery errors and content fingerprints. Do not adopt its package scanning, agent selection, symlink layout, lock format, or prompt-emitting `use` workflow: plgnz distributes plugin collections through explicit targets.

Adopt from `add-mcp`: its existing separate API only for a proven bare-MCP configuration route, with its capability-gated transform behavior. Do not absorb its registry/search, generic MCP source parsing, agent list, sync/unify commands, or config ownership into plgnz. It remains a separate API boundary.

Neither upstream supplies Agent Plugin command-to-skill conversion, plugin ownership records, native plugin-store activation, or Personal's amended-vendor preservation. plgnz therefore owns only those documented gaps. No add-on manifest, new harness, or operating-system scope follows from this review.
